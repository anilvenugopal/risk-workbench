UI preview — issue #129, Story 3. The Cedant field on Create/Edit keeps its typeahead over the active cedants. When the typed name matches no cedant exactly (case ignored), a last menu row offers to add it; clicking the row (or arrowing to it and pressing Enter) selects the typed name, and the cedant is created only when the submission saves (P-06). A typed name that matches an inactive cedant offers to reactivate it instead, also on save (P-07). Leaving the form, or a save the form refuses, writes no cedant.
Partial matches — the add row sits below them
No matches — the add row is the only row
Exact match — no add row; the analyst picks the existing cedant
Inactive match — reactivate instead of add
After the click — the typed name is selected, not yet saved
New cedant — added when you save this submission.
After the click — an inactive cedant is selected, not yet reactivated
Inactive cedant — reactivated when you save this submission.
Save refused — the new name is over 255 characters
A cedant name is at most 255 characters.
