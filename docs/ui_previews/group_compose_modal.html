Group compose dialog
Opens from the Group button in the merged analyses grid's summary bar (submission page and submission-contextual EDM page), enabled once ≥2 rows are ticked. Everything on this page is existing CSS — the .modal-card.submission-entity-modal shell, .entity-candidate-list pick-list rows, the .wf-field grid, and the currency_block macro reused verbatim from the execute modal. Nothing net-new.
State 1 · compose — two rows pre-checked, name prefilled, defaults loaded, Propagate ON

The pick-list is submission-scoped and mixes every eligible member: finished own analyses, broker analyses, and finished groups (nesting, FR-018). Running/failed rows are not listed (FR-003). The two rows ticked in the grid arrive pre-checked. The name is prefilled CRE_<submission>_Group and editable (FR-002); currency/scheme/vintage prefill from the DEFAULT_ANALYSIS_CURRENCY_* env defaults (FR-004). Propagate detailed output is ON and is the only other setting — Risk Modeler's "Create independent groups" is deliberately absent (FR-006, O-08). Submit enables at ≥2 checked members + a non-empty name + a complete currency block.
