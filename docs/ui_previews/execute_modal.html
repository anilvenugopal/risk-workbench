Execute Suite / Execute Template modal
Opens from the Portfolios header once ≥1 portfolio is checked. Same fragment for both entry points — kind=suite shows suites (expandable to their templates, deselectable); kind=template shows templates directly, no suites. Built on the existing .modal-* / .entity-candidate-* classes; the exec-* rules are net-new (T014).
