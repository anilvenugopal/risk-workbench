Package Creation modal — 3 options
Browse the shared drive from a single button, multi-select files, auto-sort them into EDM / RDM, rename in place, remove with ✕, then Save & Sync / Save / Close. Built on the app's real classes; only the clearly-marked PROPOSED CSS is net-new.
One real constraint to decide on — the "file explorer." The shared drive is mounted on the server (linux-box), and the app already reads it through a server endpoint (GET /browse) that returns server-side paths. A browser's native OS file picker can only see the analyst's own machine and hands back file bytes, not a path the server can open — so a truly "native" explorer can't feed this backend. What's shown below is therefore a server-rendered explorer in an overlay: one button opens it, you tick files, "Add" drops them into the modal. It behaves like a file browser and supports multi-select, but it's the app drawing the tree, not Windows Explorer. (If the drive is also mapped on every analyst's box and we'd rather use the native picker, that's a real fork worth a quick conversation — it changes how the backend gets the file.)
