3 · CR7 — cedant typeahead
matches
Contains-match, not prefix — today cedant_suggestions queries LIKE 'fam%', so "fam" never finds "American Family". Distinct cedant names already on submissions, capped at 10. Arrow keys move the highlight, Enter picks, Escape closes. Free text is still allowed: the cedant field has no registry behind it (FR-006).
no matches
No matching cedant yet — press Tab to use what you typed.
The first submission for a new cedant is the common case, so the empty state tells the analyst to carry on rather than reading as an error.
