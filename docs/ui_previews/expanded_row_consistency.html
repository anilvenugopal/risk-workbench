Expanded row: one layout
Every analysis type puts the same blocks in the same order. A block with nothing to show is left out.
  1. First line: analysis name · Analysis id · Submitted date, then · RDM name on a broker row.
  2. Field line: Analysis type · Subperil · Framework · Run by, always on one line.
  3. Members (group rows only): full width, five entries then +N more. A group whose members Risk Modeler does not name reads not returned.
  4. Regions & rates (every row): full width, one line per region and peril, even for a single partition.
  5. Treaties: full width, five entries then +N more. Left out when the run applied none; not returned when the read failed.
