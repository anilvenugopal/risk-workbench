## 6. Simulation periods: two settings, two defaults, one that should be read-only (D19, D20)

### 6.1 The distinction, stated cleanly for the first time

`26` **O26-8(a)** recorded Cheryl's belief that the group-level value overrides the per-row column, and Ben's plan to drop the column if so. Today he separated the two settings properly, and they are **not** the same control at two levels:

- **Per-region/peril simulation periods** — governs the **ELT→PLT conversion**, and is bounded by the chosen simulation set's own period count. *"This simulation set that we pick has a number of simulation periods built into it… So if we picked 50,000, [50,000] of the 100,000 total periods would be used. If we picked 800,000, we'd reuse them, like we said, in a different way."*
- **Group simulation periods** — governs **combining the PLTs**. *"If you picked a value different than group simulation periods, the output simulation periods of the entire group is going to match this value."*
