## 4. Origin was carrying two facts (D10–D12)

**The symptom.** Ben, demoing an RDM export: *"I just exported some from this RDM. And it is working. **It just has group which was unexpected for me.**"* His opening line had already flagged the field as wrong — *"Where did this come from? - the cart, `:280` — `origin=("broker" if r.rdm_name else "group" if d.get("is_group") else "own")`

**The client's first proposal was four values.** Wendy: *"you can have an RDM that has analyses and groups in it… and then we can have analyses and groups that we created in Risk Modeler… **I think it should say RDM or RDM group. **D10 / D11 — Ben refused the duplication and split the column instead.** *"The engine tells us whether it's a group or an analysis, straight up… **I would almost be averse to putting extra logic into this column too**, say group or analysis, because that lives in this column already."* Then: *"**Origin will mean one thing. RMS or RDM. Not group.** Even in this table… We can probably even put these two columns together in the same exact way that it looks like here… Put it next to origin column in this table, which says RMS or RDM. So then you know immediately. **This was a broker provided group. But this was a Risk Modeler executed group or analysis.**"* Cheryl: *"Yep, I agree with that."*

**There is a detour in the middle worth keeping**, because it bounds the requirement. Wendy realised she had been reading the export grid while thinking about the results grid: *"that information is valuable to me **before** I ever create the group and before I ever create the export. **D12 — and the whole thing is admitted to be a crutch.** Cheryl asked whether they need it at all; Wendy: *"I actually think it's helpful **for now**… we need some crutches to get us over the — **if we were in here 100% of the time, I might feel differently**."* Cheryl agreed on that basis: *"just because we're working across two different systems."* Ben: *"the mechanism is already there, so yeah, we can retain it."* **Record the expiry condition with the requirement; this is a column that is supposed to stop earning its place.**
